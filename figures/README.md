# Figures of the front pages

The front pages and the card embed these figures. Each figure is an SVG rendered from the `.dot` source beside it, the source that the [figure shape](../shapes/figure.md) asks to keep. To render a figure again from its source, run `python3 checks/render_figure.py figures/NAME.dot`.

| Source | Drawn in |
|---|---|
| [scope.dot](scope.dot) | [README.md](../README.md): the base, its three contexts, and a personal style |
| [scope.fr.dot](scope.fr.dot) | [README.fr.md](../README.fr.md): the same, in French |
| [how-to-use.dot](how-to-use.dot) | [standard.md](../standard.md): the four steps, and what to do with each kind of finding |
