# Shapes

A **shape** is the fixed skeleton of one kind of document: every document of that kind has the same parts in the same order. These are the shapes particular to presentations. The general ones are in [reader-ergonomics](https://github.com/Tewf/reader-ergonomics/tree/v1.7.0/shapes).

## Contents

| Shape | For |
|---|---|
| [talk.md](talk.md) | a spoken talk with slides, as a slide-by-slide outline in any tool |
| [example-talk.html](example-talk.html) | the talk shape built as an HTML deck, one `<section>` per slide, with [example-talk.css](example-talk.css); it passes every deck check |
| [figure.md](figure.md) | a figure or a diagram in any document of the family: caption, drawing from a `.dot` source, alt text, long description |
| [example-figure.dot](example-figure.dot) | the figure shape filled: its source, rendered to [example-figure.svg](example-figure.svg) |
